# Release starting points

- [preflight.sh](preflight.sh): copy to `tools/preflight.sh`, set `RELEASE_REPO` and `RELEASE_WORKFLOW` (the workflow FILE name, default `release.yml`) as needed. Copy the matching [Electron job list](electron-preflight-jobs.txt) or [Tauri job list](tauri-preflight-jobs.txt) to `.github/release-preflight-jobs.txt` and adapt every expected matrix-expanded job name. Override its path with `RELEASE_EXPECTED_JOBS_FILE`. The helper rejects missing expected jobs, every skipped job except `publish` and `Hand off to the bot` (the handoff job is skipped in the bot's run), and every failed step. It waits for the bot's run, not its own dispatched run. Both examples name the non-publishing job exactly `publish`; adapt that filter if the target uses another name.
- [electron-release.yml](electron-release.yml): macOS arm64/x64 DMG/ZIP, Windows x64 EXE, Linux x64 AppImage/DEB. Uses `package.json` and both root version entries in `package-lock.json`, `v` tags, Node 24, and the target project's `scripts/package.mjs` and `scripts/audit-release.mjs`.
- [tauri-release.yml](tauri-release.yml): Expo web app plus Tauri desktop, bare version tags, Windows x64 MSI/EXE, macOS arm64 DMG, and Linux x64 AppImage/DEB. Uses `apps/app/app.json`, `desktop/package.json`, Tauri JSON and Cargo metadata. It expects the target's export, asset-check and smoke scripts.

The YAML files are examples adapted from working pipelines, not drop-in workflows for every repository. Replace `ExampleApp`/`exampleapp`, version-file paths, tag style, package identifiers, commands, executable names, expected assets, architecture and signing-secret names with the inspected project's actual values. Check every referenced local script exists and runs on that platform. These examples require all included tests; when an existing target explicitly allows informational tests, adapt the helper to identify and report those exceptions without ignoring installer failures. Run the adapted workflow's complete preflight before publishing.

Both workflows follow the quiet-CI contract ([ci.md](../../../ci.md)): keep the `handoff` job verbatim, `if: github.triggering_actor == 'github-actions[bot]'` on every other job, `continue-on-error: true` everywhere, and the `attempt` retry in `publish`. Retry a release with `gh workflow run release.yml --ref <tag> -f tag=<tag>`, never `gh run rerun`. The Tauri `need_*` outputs and asset-name regexes in `prepare` must match the adapted installer names.

Preflight builds the dispatched commit even when a tag input is present. Manual publication builds the existing tag. No sample uploads to Actions artifact storage. A tagged source archive must meet the same privacy check as release notes and binaries.
